# RoofStudio v0.8 — чердак, вентиляционные шахты и предварительный разрез

## Что добавлено

- Вкладка **«Чердак»**. План чердака строится по обмерному наружному контуру с отступом внутрь на фактическую толщину стены.
- Выпадающий список типа дома: **кирпичный, панельный, блочный, другой**. Предустановленные толщины 380/510/640, 300/350/400, 300/400/500 мм — только редактируемые стартовые варианты, **не нормативная таблица**. Для реального проекта вводите обмеренную/подтверждённую толщину.
- Вкладка **«Каталог ВШ»**. Пользователь может добавлять, редактировать и удалять типы ВШ (марка, сборная/ж/б/блочная, наружные размеры, толщина стенки, утепление, возвышение над кровлей). Есть пример ВШ1 500×500 мм.
- На плане чердака можно **размещать, выделять, перетаскивать, поворачивать на 90° и удалять** экземпляры ВШ; количество экземпляров считается автоматически.
- Вкладка **«Разрез 1–1»**. Вводится высота наружной стены **от шлака** и расположение поперечного разреза по координате X. Показываются скаты, стена от шлака, ВШ, размер возвышения ВШ над кровлей и длинный размер **от шлака до верха ВШ**.
- Округление **всех выносных вертикальных размеров ВШ вверх до 5 мм**, при этом в проекте сохраняются фактические числовые значения.
- При несогласованности заданного уклона со значением отметки конька выводится разница в мм, автоматически инженерные размеры не искажаются.
- Предварительная ведомость: площадь чердака, длины/габариты ВШ, наружная обшивка выше кровли, объём утеплителя выше кровли и в чердаке, объём материала стен ВШ.
- Кнопки **«DXF чердака»** и **«DXF разреза»** создают редактируемые DXF (мм, 1:1) без внешних библиотек.
- Сохранение проекта в JSON вместе с каталогом и координатами ВШ. Предыдущие проекты без раздела `attic` открываются с начальными настройками.
- Иконка приложения осталась пользовательской (из предыдущей версии).

## Как работать

1. На вкладке «Контур здания» создайте прямоугольный, Г-образный или произвольный замкнутый контур. Или задайте длину и ширину прямоугольного здания в «Геометрии».
2. Откройте «Чердак», выберите тип стены, задайте **фактическую толщину** и **высоту стены от шлака**, нажмите «Применить».
3. На вкладке «Каталог ВШ» задайте нужные марки и размеры шахт.
4. Вернитесь в «Чердак», выберите марку, нажмите «+ Разместить ВШ» и щёлкните внутри голубого внутреннего контура. Размещённые объекты можно перетаскивать.
5. Откройте «Разрез 1–1», задайте положение сечения X. На разрез попадут ВШ, пересекаемые секущей линией.
6. В боковой панели задайте отметку конька от уровня шлака, м. Сравните уклон по разрезу с заданным и оцените предупреждение о расхождении.
7. Сохраните `.roof.json`, выгрузите DXF или ознакомьтесь с предварительной ведомостью.

В комплекте есть `Пример_Г_образного_дома_с_ВШ.roof.json`.

## Ограничения и инженерные допущения

- Внутренний контур рассчитывается как равномерный отступ наружного контура. Для сложных неортогональных геометрий, разных толщин стен, выступов или шахт у внешних стен требуется проверка.
- **Сложная крыша v0.7 пока использует приближённый алгоритм скатов**, а не точные пересечения трёхмерных плоскостей. Поэтому плановые и вертикальные расчёты — предварительные.
- Высота ската в точке ВШ определяется по условному поперечному разрезу. Вальмы, ендовы, разные коньки и несимметричные крыши требуют отдельной точной геометрии. На этой версии не используйте рассчитанные площади и высоты для заказа материалов без ручной проверки.
- Номенклатура ВШ, выступ над кровлей, выбор конструкций и требования действующих СП/ГОСТ должны проверяться проектировщиком. Программа не заменяет нормативный расчёт.
- Площадь утепления чердака по периметру здания и площадь шахт — разные величины: в этой версии площадь внутреннего контура дана отдельно, вычет шахт из теплоизоляции чердака пока **не автоматизирован**.
- Ведомость не включает запасы, отходы, нахлёсты и переходные детали.

## Windows EXE без установки Python на целевом компьютере

1. Загрузите в GitHub **содержимое** архива (особенно новые `attic_model.py`, `attic_ui.py`, `attic_cad_export.py` и изменённые `roofstudio.py`, `.github/workflows/build-windows.yml`).
2. На странице репозитория выберите **Actions → Build RoofStudio Windows EXE → Run workflow**.
3. После успешного выполнения загрузите артефакт `RoofStudio_v0.8_Windows_x64`, внутри будет `RoofStudio_v0.8.exe`.

На Windows достаточно скачанного EXE. Сборка Windows через GitHub в этой среде не проверялась, но код Python, модули геометрии и тесты GUI под виртуальным экраном проверены.
